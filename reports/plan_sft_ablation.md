## A v2: plans write "?" for values not yet visible (2026-11-09)

Root cause of A v1's loss: in 99/309 test samples the plan target held values the model could only know after a tool result.
A v2 retrains A with those values written "?" (`scripts/plan_data.py`, `docs/plan_format.md`); same steps, data otherwise identical, B not retrained.
147 steps, 12.3M tokens, 8.6 h, val loss 0.0484.

| Run | All (309) | "?" samples (99) | Other (210) |
|---|---:|---:|---:|
| Base | 18.3 | 6 | 24 |
| A v1 | 44.9 | 33 | 51 |
| A v2 | 46.4 | 41 | 49 |
| B | 49.3 | 48 | 50 |
| B + top-5 app filter | 50.4 | 48 | 52 |

Paired differences, 95% bootstrap CI: A v2 - A v1 = +1.5 (-2..+5); A v2 - B = -2.9 (-8..+2).
The "?" plans close half of the gap on the samples they target (33 -> 41 vs B 48) but A still trails B overall.
EDA, A v2 vs B: 2 under-calls 33.7% vs 23.0%, 1c wrong value 25.9% vs 19.7%, 7 multi-step mean score 40.0 vs 50.2.
A v2 was trained before a later fix of the "visible" check (a number said in words was "?" though the prompt shows digits; 96/2352 train rows).
