# Vietnamese spell correction benchmark

Generated by `kaggle/spell_eval/run.py` on CV5 fold 0, with 309 held-out utterances.

WER uses the same normalization as `scripts/asr_report.py`: lowercase NFC, remove punctuation, and convert number words 0-10 to digits.

The baseline is the fine-tuned PhoWhisper transcript, evaluated on the same final-turn samples.

| System | WER | Absolute change vs PhoWhisper |
|---|---:|---:|
| PhoWhisper FT | 0.1530 | - |
| `nrl-ai/vn-spell-correction-small` | 0.1778 | +0.0248 |
| Spell correction SFT on folds 1-4 (1,236 pairs, 2 epochs) | 0.1619 | +0.0089 |

The correction model reduced WER by 0.0159 versus its own base checkpoint after SFT, but still increased WER by 0.0089 versus leaving PhoWhisper unchanged.

Do not add this correction model to the ASR inference path based on this result.

The Kaggle job saved the SFT checkpoint under `work/kaggle/spell_eval_output/out/vn-spell-correction-small-sft` for further experiments.
